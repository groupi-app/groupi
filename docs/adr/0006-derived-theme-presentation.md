# Derive interaction treatment without expanding saved theme configuration

Groupi preserves users' selected theme fills and derives readable foregrounds,
interaction colors, and Soft lift backing through common rules consumed by web
and native. These presentation values do not introduce required saved-theme
fields or new border/depth controls in the initial refresh: this trades granular
customization for compatible saved themes and consistent interaction across
platforms. See the [design language refresh plan](../design-language-refresh-plan.md)
for rollout and verification.
