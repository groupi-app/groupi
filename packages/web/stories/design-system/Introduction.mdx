# Groupi design system

Groupi uses semantic design tokens and reusable components across its web UI.
The current Soft lift treatment uses sticker edges, backing depth, and distinct
focus and pressed states.

## Table of Contents

- [Tokens](#tokens)
- [Motion and interaction](#motion-and-interaction)

## Tokens

The token system has three layers:

1. Primitives define raw colors, spacing, and dimensions.
2. Semantic tokens describe purpose, such as surfaces and feedback.
3. Component tokens define individual control and layout treatments.

Use semantic and component tokens so bundled and custom themes remain consistent.
Avoid copying a theme's raw color or radius into application components.

## Motion and interaction

Filled actions depress on hover and press. Passive cards remain still. Reduced
motion keeps position fixed while colors and depth communicate state. Components
must preserve keyboard focus, accessible names, disabled behavior, and readable
loading and error states.

## Review

Start with the Soft lift overview and application-default stories. Review light,
dark, and sparse custom themes, portaled content, narrow layouts, and enlarged
text. Follow the interaction checks in the colocated `README.md` and the root
`docs/ui-design-system.md` guide.
